# Portfólio — Leonardo Aires de Oliveira

Site pessoal com meu portfólio em Engenharia de Dados / Ciência de Dados, publicado via GitHub Pages.

## Sobre

Página estática, sem frameworks ou build step — um único `index.html` com HTML, CSS e SVG embutidos. Foco em um layout limpo e monocromático, pensado para leitura rápida por recrutadores.

## Estrutura

```
.
├── index.html              # página principal
├── assets/
│   └── curriculo-leonardo-aires.pdf
└── README.md
```

## Rodando localmente

Não há dependências de build. Basta abrir o `index.html` no navegador, ou servir a pasta localmente:

```bash
python -m http.server 8000
```

e acessar `http://localhost:8000`.

## Publicação

O site é servido pelo GitHub Pages a partir da branch `main`, raiz do repositório (Settings → Pages).
